# How to Run the Dictionary App

1.  **Locate the Files**: Go to the folder `c:\Users\venka\dictionar_app`.
2.  **Open the Application**: Double-click on the `index.html` file. It should open in your default web browser (Chrome, Edge, Firefox, etc.).
3.  **Use the App**: Type a word into the search box and press "Search" or hit Enter.

No additional server or installation is required since this is a static web application.
